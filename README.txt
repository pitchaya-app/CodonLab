CODONLAB COMPETITION WEBSITE
=============================

ไฟล์หลัก
- index.html
- style.css
- app.js
- assets/hero-codonlab.svg
- assets/activities/activity-01.svg ... activity-06.svg

วิธีเปิดดู
1. ดับเบิลคลิก index.html
2. หรือใช้ VS Code + Live Server

วิธีเปลี่ยนภาพกิจกรรม
- นำภาพจริงมาใส่ใน assets/activities/
- เปลี่ยนชื่อเป็น:
  activity-01.jpg
  activity-02.jpg
  ...
- แล้วแก้ .svg เป็น .jpg ใน index.html

จุดที่ควรแก้ก่อนนำไปประกวด
1. ชื่อผู้พัฒนา
2. โรงเรียน / หน่วยงาน
3. รูปผู้พัฒนา
4. ภาพกิจกรรมจริง
5. ลิงก์คู่มือ / แผน / แบบประเมิน
6. QR Code จริง
7. ตรวจสอบตัวเลขผลลัพธ์และข้อความให้ตรงกับรายงานฉบับสุดท้าย

GitHub Pages
1. สร้าง Repository เช่น CodonLab
2. อัปโหลดไฟล์ทั้งหมด
3. Settings > Pages
4. Deploy from a branch
5. Branch: main / root
6. Save

หมายเหตุ:
เว็บไซต์นี้ไม่ใช้ Framework และไม่ต้องมี Backend
จึงเหมาะกับ GitHub Pages โดยตรง
